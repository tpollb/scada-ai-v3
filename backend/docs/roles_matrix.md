## Предопределённые роли

| Роль | Описание | Уровень доступа |
|------|----------|-----------------|
| `admin` | Администратор системы | Полный доступ ко всем функциям |
| `engineer` | Инженер-настройщик | Все функции кроме управления пользователями |
| `operator` | Диспетчер/Оператор | Мониторинг и базовое управление |
| `boss` | Руководитель | Только аналитика и отчёты |

## API Endpoints

### Аутентификация
- `POST /api/auth/login` - Вход в систему (получение JWT токена)
- `GET /api/auth/me` - Получение данных текущего пользователя
- `GET /api/auth/permissions` - Получение разрешений текущего пользователя

### Пользователи (требует роль admin)
- `GET /api/auth/users/` - Список всех пользователей
- `POST /api/auth/users/` - Создание пользователя

### Роли (требует роль admin/engineer)
- `GET /api/auth/roles/` - Список всех ролей с разрешениями
- `GET /api/auth/roles/{role_name}/permissions` - Разрешения конкретной роли

## Примеры использования

### curl - получение токена
```bash
curl -X POST "http://localhost:8000/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "admin123"}'
```

### curl - доступ к защищённому endpoint
```bash
curl -X GET "http://localhost:8000/api/auth/me" \
  -H "Authorization: Bearer <your_token>"
```

### Swagger UI
Откройте `http://localhost:8000/docs` и используйте кнопку "Authorize" для ввода учетных данных.
